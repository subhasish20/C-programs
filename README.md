# 💻 C Programs Collection

Welcome to the **C Programs Collection**! 🚀

This repository contains a collection of C programming examples created for learning, practicing, and improving problem-solving skills using the C language. 🧠✨

## 📌 About This Repository

This repo includes various C programs covering fundamental programming concepts such as:

* 🔹 Basic input and output operations
* 🔹 Variables and data types
* 🔹 Conditional statements (`if`, `else`, `switch`)
* 🔹 Loops (`for`, `while`, `do-while`)
* 🔹 Functions
* 🔹 Arrays
* 🔹 Strings
* 🔹 Pointers
* 🔹 Structures
* 🔹 File handling
* 🔹 Common programming problems and solutions

## 🛠️ Technologies Used

* 💻 **Programming Language:** C
* 🖥️ **Compiler:** GCC / Any C Compiler
* 📚 **Purpose:** Learning and practice

## 🚀 How to Run the Programs

1. Clone this repository:

   ```bash
   git clone <repository-link>
   ```

2. Navigate to the project folder:

   ```bash
   cd C-programs
   ```

3. Compile any C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program:

   ```bash
   ./output
   ```
